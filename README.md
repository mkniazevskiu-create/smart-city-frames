# Фреймовая модель критической инфраструктуры умного города

Проект демонстрирует представление знаний о критической инфраструктуре умного города с помощью **фреймовой модели**:

- **классы Python** выступают как **фреймы**;
- атрибуты объектов — как **слоты**;
- используется **наследование слотов** (общие и специфические атрибуты);
- задаются **связи** между объектами (`depends_on`);
- реализованы запросы к базе знаний и демонстрационный анализ: **цепочка зависимостей**, **каскад отказа**, **оценка риска**.

Результат работы — **интерактивный отчёт `report.html`**, который открывается в браузере **без сервера**.

---

## Структура проекта

.
├─ frames.py # классы-фреймы и наследование слотов
├─ kb.py # демонстрационная база знаний (объекты и связи)
├─ queries.py # запросы: карточка, цепочка зависимостей, каскад отказа, риск-правила
├─ report.py # генерация интерактивного report.html (HTML+CSS+JS внутри одного файла)
├─ main.py # запуск: сборка базы и генерация отчёта
├─ report.html # пример уже сгенерированного отчёта (можно открыть сразу)
└─ README.md

## Требования

- Python 3.x  
- Внешние библиотеки не требуются (проект работает на стандартной библиотеке Python).

1) Перейдите в папку проекта:
```bash
cd smart-city-frames

2) Запустите генерацию отчёта:

(Если команда py не работает, используйте python main.py.)
